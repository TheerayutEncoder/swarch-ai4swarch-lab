# การ์ดบทบาทสำหรับคณะกรรมการรีวิว

ผู้มีส่วนได้ส่วนเสีย: เปิดอ่าน**เฉพาะการ์ดของตัวเอง** และเก็บข้อเท็จจริงในการ์ดไว้เป็นความลับจนถึงเวลาประชุม

| การ์ด | บทบาท |
|---|---|
| [P: Product owner](card-P-product-owner.md) | ธุรกิจ ลูกค้า กำหนดส่ง |
| [S: Site reliability engineer](card-S-sre.md) | ปฏิบัติการ เวร on-call ค่าใช้จ่าย |
| [X: เจ้าหน้าที่ความปลอดภัยและความเป็นส่วนตัว](card-X-security-privacy.md) | เฉพาะกลุ่ม 5 คน |

การ์ดเหล่านี้เป็นส่วนหนึ่งของสถานการณ์สมมติใน [`../scenario.th.md`](../scenario.th.md) ให้ถือว่าข้อเท็จจริงในการ์ดเป็นความจริง และ AI **ไม่เคย**ได้เห็นการ์ดเหล่านี้
